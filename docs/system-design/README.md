# 시스템 설계 문서

이 폴더는 게임의 내부 시스템과 규칙을 관리합니다.

## 기록 대상

- 자원 구조
- 상태값 변화 규칙
- 하루 진행 흐름
- 이벤트 발생 조건
- 선택지 결과 처리
- 난이도/밸런스 기준
- 저장/불러오기 구조
- 향후 구현을 위한 시스템 명세

## 주요 자원 후보

- 혈액 재고
- 가문 자금
- 가문 위신
- 인간 신뢰
- 언론 노출
- 조직 불안
- 보안 등급
- 가문 만족도
