## 2. 검증 시나리오 (요구사항 7단계 대응)
- **역할별 접근**: 부서원이 사용자/인적사항 API 호출 시 403. 관리자만 200. ✅
- **부서별 접근**: 석유사업부원은 전략기획실 부서전용 업무일지 미표시/직접접근 차단. ✅
- **개인정보 접근**: 목록 마스킹, 목적 없는 상세 400, 목적 입력 후 원문 200, pii.read 없는 감사자 403. ✅
- **API 직접 호출**: 비로그인 401, 권한 없는 사용자 직접 호출 403(화면 숨김에 의존 안 함). ✅
- **동시 수정**: 낡은 version 저장 시 409 충돌 감지. ✅
- **모바일 화면**: 820px 이하에서 하단 메뉴 전환, 가로 스크롤 최소화(테이블만 개별 스크롤). ✅(반응형 CSS)
- **잘못된 입력**: 필수값 누락/잘못된 JSON/짧은 비밀번호 → 한국어 안내 오류. ✅
- **로그아웃·세션 만료**: 로그아웃 후 세션 무효화(401), 8시간 만료. ✅
- **계정 정지**: 정지 시 로그인 차단 + 활성 세션 종료. ✅
