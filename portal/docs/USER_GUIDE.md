# 사용자 가이드 (USER_GUIDE)

## 로그인
1. 브라우저에서 포털 주소 접속 → 이메일·비밀번호 입력 → **로그인**.
2. 비밀번호 5회 틀리면 15분 잠깁니다. 잠기면 잠시 후 다시 시도하세요.
3. 좌측(모바일은 하단) 메뉴는 **본인 권한에 허용된 항목만** 보입니다.

## 대시보드
로그인 직후 화면. 내 미완료 업무, (권한에 따라) 승인 대기·사용자 수·최근 활동 등을 요약합니다.
권한이 없는 정보는 아예 표시되지 않습니다.

## 업무일지
- **새 업무일지**: 제목·내용·상태·우선순위·공개범위 입력 후 저장.
- **공개범위**: 전체/전 조합원/임직원/부서 공개/작성자·관리자만 중 선택. 선택에 따라 다른 사람에게
  보이는 범위가 달라집니다(부서 공개는 같은 부서만).
- **수정 중 충돌**: 다른 사람이 먼저 저장하면 "다른 사용자가 이미 수정했습니다" 안내가 뜹니다.
  새로고침으로 최신 내용을 확인한 뒤 다시 저장하세요(내용이 덮어써지지 않습니다).
- **검색/필터**: 상태·검색어로 좁혀 봅니다.

## 조합원·임직원 인적사항 (권한 필요)
- 목록의 이름·연락처·생년월일은 **가려져(마스킹)** 표시됩니다.
- 원문을 보려면 **상세 열람** → **열람 목적**을 입력해야 하며, 이 열람은 기록으로 남습니다.
- 권한이 없으면 목록/상세에 접근할 수 없습니다(접근 제한 안내).

## 내 정보
본인 계정 정보 확인, **비밀번호 변경**(8자 이상).

## 자주 겪는 안내 메시지
- "로그인이 필요합니다" → 세션 만료. 다시 로그인하세요.
- "이 기능에 접근할 권한이 없습니다" → 관리자에게 권한을 요청하세요.
- "열람 목적을 입력해야 상세를 볼 수 있습니다" → 개인정보 보호를 위한 필수 절차입니다.
