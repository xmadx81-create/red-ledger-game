# 미완료 및 향후 개선사항 (ROADMAP / UNDONE)

정직하게, **아직 구현하지 않은** 기능을 완료로 표시하지 않고 여기 모읍니다.

## 미구현 기능 (후속 개발)
- **공용 파일함**: 업로드/다운로드/버전관리/서명URL/미리보기/삭제복구/저장공간 연동. (스키마·보안 방침만 문서화)
- **업무 매뉴얼**: 웹에디터·버전이력·검토/승인·PDF 출력·즐겨찾기.
- **업무관리 고급**: 칸반/캘린더 보기, 체크리스트, 하위업무, 반복업무, 담당자별 업무량 집계.
- **공지사항 / 알림센터**: 게시·읽음확인·상단고정 / 앱 내 알림(이메일·문자·카카오는 더 후속).
- **개인정보 수정요청→관리자 승인** 워크플로우, 엑셀 가져오기/내보내기, 중복확인.
- **업무일지 부가**: 댓글/피드백, 엑셀·CSV 내보내기, 일·주·월 보기, 복사/이어쓰기, 변경이력 UI.

## 보안·운영 개선 (알려진 미완료)
- CSRF 이중 제출 토큰 / Origin 화이트리스트(현재 httpOnly+SameSite=Strict 의존).
- 쿠키 `Secure` 속성(운영 HTTPS 전제), 세션 회전·다중기기 관리 UI.
- 로그인 외 API의 Rate limiting, 비밀번호 복잡도·만료 정책.
- 감사 로그 무결성 강화(해시체인/외부 적재), 개인정보 열람이력 보존기간·파기정책.
- 파일 업로드 보안 일체(확장자/크기/MIME/백신).

## 아키텍처 전환 (프로덕션)
- SQLite → PostgreSQL(Supabase) 이식, 서버 권한판정 → **RLS 정책** 이관.
- Supabase Auth 연동, Supabase Realtime로 실시간 갱신, Next.js/Tailwind 프론트 이식.
- 멀티조직(`organization_id`) 실사용 활성화.

2. 업무 매뉴얼(버전·승인)
3. 공지사항 + 앱 내 알림
4. PostgreSQL/RLS 전환 + Supabase Realtime
